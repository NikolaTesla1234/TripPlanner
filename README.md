# 🗺️ TripPlanner — Клиент-серверное веб-приложение с авторизацией


Учебный проект по теме **9: Планировщик поездок** (Учебная практика, 3 курс).

## 🛠 Стек технологий
- **Backend:** FastAPI, SQLAlchemy 2.0, SQLite, Alembic (миграции)
- **Авторизация:** JWT-токен в cookie (сессия), пароли хешируются через bcrypt
- **Фронтенд:** HTML/CSS, шаблоны Jinja2 (server-side rendering, без fetch)
- **Версии:** Git с регулярными коммитами по этапам

## 📋 Функциональность
- Регистрация и вход (проверка длины логина/пароля ≥ 3)
- Выход (удаление cookie)
- Пользователь видит только свои поездки
- CRUD поездок: создать, посмотреть, редактировать, удалить
- Пункты плана поездки с датами
- Лайк поездки
- Статистика: общее количество поездок, сумма и средний бюджет, группировка по направлениям
- API эндпоинты: `/api/users/`, `/api/trips/`

## 🚀 Запуск
Дважды нажмите на `run.bat`, либо в терминале:

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000`.

## 📊 Этапы разработки (коммиты в Git)
1. Проектирование — модели User, Trip, PlanItem
2. Миграции и модели — Alembic, SQLAlchemy
3. Авторизация API — регистрация, вход, сессия через cookie
4. API сущностей — CRUD поездок, план, лайки
5. Фронтенд — HTML-страницы на Jinja2
6. Работа и сдача — тестирование, README, демо
